# Демо: языковая модель на ESP32-S3 в реальном времени

Плата с прошитой моделью подключается к любому компьютеру по USB. Страница в браузере отправляет
начало истории, плата дописывает её по токену и сразу отправляет каждый новый токен. Все вычисления
идут на плате, компьютер только переводит текст в токены и показывает результат.

## Для коллег: как запустить (без установки программ)

1. Подключите плату USB-кабелем к разъёму **COM** (UART).
   Windows 10/11 обычно сама ставит драйвер CH343; если порт не появился, нужен драйвер WCH CH343.
2. Откройте `index.html` из этой папки в **Google Chrome** или **Microsoft Edge**. Нужны все три файла
   рядом: `index.html`, `tokenizers.js`, `bpe.js`. Firefox и Safari не умеют подключаться к USB-портам.
3. Нажмите **«Подключить плату»**, выберите порт `USB-Enhanced-SERIAL CH343` → «Подключиться».
4. Введите начало истории по-английски или выберите пример и нажмите **«Написать»**.

Модель училась на детских рассказах (TinyStories). Два режима:
- **«Продолжить историю»**: модель дописывает начатую историю (любая модель).
- **«Вопрос по сказке»**: вставьте сказку и задайте простой вопрос по ней (как зовут героя, кто он, куда пошёл, что нашёл, что чувствовал, что сказал). Нужна модель `combo_qa_s0`, см. `docs/qa-finetune.md`.

## Для владельца платы: как прошить демо

```sh
# сборка прошивки-демо (ESP-IDF 5.5, PowerShell с профилем IDF):
#   cd engine/esp32
#   idf.py -B builddemo -D SDKCONFIG=sdkconfig.demo -DLLM_DEMO=1 build
# прошивка демо + модель (esp32ai_ts = модель esp32-ai, 29 млн; combo_s0 = наша, 2 млн):
engine/demo/flash_demo.sh COM6 esp32ai_ts
# модель, которая отвечает на вопросы по сказке:
engine/demo/flash_demo.sh COM6 combo_qa_s0
```

Пакеты моделей делают `engine/export_esp32ai.py` и `engine/export.py combo_s0`.
Словари для страницы пересобирает `engine/demo/build_tokenizers.py`.

## Протокол (UART, 115200 бод)

| Направление | Строка | Смысл |
|---|---|---|
| ПК → плата | `I` | повторить строку READY |
| ПК → плата | `G max temp×1000 topk seed eot n id1 … idn` | дописать эти n токенов |
| ПК → плата | `X` | остановить генерацию |
| ПК → плата | `H доля` | доля строк словаря, которую читает выбор слова (1 — весь словарь; для вопросов) |
| ПК → плата | `K n id1 … idn` | добавить токены, на которых кончается пропуск шаблона (`K 0` — очистить) |
| ПК → плата | `S maxslot temp×1000 topk seed eot batch nseg сегменты…` | заполнить шаблон: сегмент `0 n id…` — известный текст, `1` — пропуск; batch 1 — известный текст пакетами, 0 — по одному токену |
| плата → ПК | `READY {json}` | размеры модели, частота PSRAM, доля строк выбора слова |
| плата → ПК | `P мс` | начало обработано (пакетами по 16 токенов) |
| плата → ПК | `T id мкс` | новый токен и время предыдущего шага |
| плата → ПК | `E n мс_на_токен` | генерация закончена |
| плата → ПК | `Q n мс id…` | кусок шаблона обработан |
| плата → ПК | `R ген извест мс_ген мс_извест` | шаблон заполнен |

Проверка шаблонов на плате: `.venv/Scripts/python engine/template_test.py --port COM6`.

«Точно» означает жадный выбор, «Живо» и «Смело» — выбор из 40 лучших токенов при температуре 0,7 и 1,0.
